# Security policy

tvt-lab is a test bench for [tvt](https://github.com/opsmastery/tvt). Report a
vulnerability privately through this repository's **Security** tab
(Report a vulnerability), or email security@opsmastery.dev. Please don't open a
public issue for a security problem.

The lab runs seeded, synthetic data only. No real credentials belong in this
repository; push protection and secret scanning are on.
